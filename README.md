# Base & Traço — Site de Arquitetura
Este site é a recriação do protótipo do figma proposto pela atividade, feito em React, Vite e React Router.

## Integrantes da dupla

- Diego André Rantes Davila
- Gustavo dos Santos Ferreira

## Descrição
Site de arquitetura entitulado como "Base&Traço", que em sua página home apresenta, alguns projetos, informações sobre a empresa, o tipo de serviço oferecido. Além do cabeçario que redireciona o usuário para as devidas páginas, como "projetos", "sobre" e "Contato". O Footer funcional em todas a páginas do site. Tanto o footer quanto o header são componentes reutilizados em todas as páginas.
